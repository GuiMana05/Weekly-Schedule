# Weekly Schedule

A simple web app to plan your week. Organise classes, work and tasks in one clear weekly view.

**Live demo:** https://GuiMana05.github.io/Weekly-Schedule/

## Features

- **Weekly view:** see your whole week at a glance.
- **Plan your time:** add and organise classes, work shifts and tasks.
- **Zero setup:** open the page and start planning, no account or installation needed.

## Tech

- Single-file app: plain HTML, CSS and JavaScript, no build step and no dependencies to install.
- Client-side only: no backend, your data stays in your browser.

## Run it locally

1. Download `index.html`.
2. Open it in any modern browser.
